Features

Built to just work

Everything here is in the free download. No accounts, no subscriptions.

  • Run profiles side by side. Give each profile its own key, then start or stop any of them from anywhere, even while another one runs. New
  • Pick any key on a keyboard. Every key setting opens a full-size keyboard and mouse: click the key, or just press it. Every key works, both Shifts, Ctrls and Alts and the whole numpad included. New
  • Instant stop. Press the start key again and the macro ends that moment, even halfway through a long wait or a held key. Anything it was holding is let go. New
  • Record and replay. Key holds, combos, mouse drags, side buttons and scrolling are kept, and playback timing is accurate to about a millisecond.
  • Scroll steps. Scroll up, down, left or right, wherever the mouse is or at a set spot, spread over as long as you like.
  • Fast detection. Checks a full screen of images in a fraction of a second. Star the important ones to check them first.
  • Works on changing backgrounds. Merge a few snips of the same button and MacroEZ learns its outline, so whatever is behind it doesn't matter.
  • Backup detection. If the normal check misses, a second method looks for the button's shape.
  • Safe zones. Draw areas it must never click, like a close button or a Send button.
  • Profiles. Save as many macros as you like and switch between them. A running one keeps going while you switch.
  • Hotkeys you choose. Start, stop, snip and test from inside any app, with any key or mouse button. Each mode can have its own start and stop keys too.
  • Only runs where you want. Each mode can be tied to one app, and it waits whenever that app isn't in front.
  • One file. No installer and no account. Your macros are saved in the same folder.
