Getting started

  1. 1

    Give it a folder

    Move MacroEZ.exe into its own folder, like Documents\MacroEZ. Your macros are saved next to it.

  2. 2

    Open it

    If Windows says "Windows protected your PC", click More info, then Run anyway. Why?

  3. 3

    Pick a mode

    Choose a mode on the left, set it up, then press F6 to start and stop. See the modes

Updating? Replace the old MacroEZ.exe with the new one in the same folder. Your macros stay.
