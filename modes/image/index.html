Mode guide

Image mode

Show MacroEZ the buttons you keep clicking, like Accept, Next or OK. It watches the screen and clicks each one the moment it appears.

Good for: Clicking through installers, approval queues, popups and anything else that keeps asking you to press the same buttons.

1

Snip the buttons to click

Open Image on the left. Press F7 or + Snip, then drag a box around a button on your screen. Do the same for every button you want clicked. They're checked top to bottom.

  1. + Snip adds a button. You can also add picture files or paste one.
  2. Your click list. Click the Priority column to ★ an image so it's checked on every scan.
2

Fine-tune each one

Select an image to adjust it on the right. Min match sets how closely the screen has to match. Lower it a little if a button isn't being found, raise it if the wrong thing gets clicked. Wait before reclick stops it clicking the same button twice in a row.

  1. The selected image's settings. Use Crop image to trim a snip, or Merge selected to teach it a button that sits on changing backgrounds.
3

Add recovery steps (optional)

If something can interrupt the job, like a sign-in screen or an error box, add it under Recovery. When step 1 shows up, the click list pauses and these get clicked in order until things are back to normal.

  1. Recovery steps, clicked in order whenever the first one appears.
4

Choose where it runs and what else it does

Runs in keeps it to one app, and it waits whenever that app isn't in front. Repeat a key can press a key over and over between clicks, like Enter to confirm each dialog.

  1. Pick the app it works in, and its own start and stop keys if you like.
  2. An optional key to keep pressing. Click the key box to pick from a full keyboard.
5

Press F6 to start

Press F6 or the Start button. The Match column shows how well each button matches the screen right now, and the Activity log lists every click. Press F6 again to stop instantly.

  1. Start and stop. The button shows the key that does the same.
  2. What it's doing right now and how many clicks it's made.
  3. Live match scores for each button.
